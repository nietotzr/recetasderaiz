Política de privacidad

Cómo se tratarán los datos personales cuando la web incorpore formularios, analítica, publicidad u otros servicios.

1. Responsable

Responsable: El propietario del sitio web.

2. Datos tratados actualmente

La versión actual del sitio no incluye registro de usuarios, newsletter ni formulario de contacto. El gestor de consentimiento guarda únicamente las preferencias de cookies en el propio navegador.

3. Servicios futuros

Si se incorporan analítica, publicidad, newsletter, comentarios o formularios, esta política deberá actualizarse antes de activarlos, indicando proveedor, finalidad, base jurídica, conservación, destinatarios y posibles transferencias internacionales.

4. Derechos

Cuando exista tratamiento de datos personales, podrás solicitar acceso, rectificación, supresión, oposición, limitación y portabilidad a través de los medios de contacto que habilite el propietario del sitio web. También podrás reclamar ante la Agencia Española de Protección de Datos.

5. Seguridad y conservación

Se aplicarán medidas razonables para proteger los datos y se conservarán solo durante el tiempo necesario para cada finalidad o para atender obligaciones legales.

6. Cambios

Esta política podrá actualizarse cuando cambien los servicios o las obligaciones aplicables.
